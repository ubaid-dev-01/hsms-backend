# Deploy — hsms-backend

## Vercel project
- Name: `hsms-backend`
- GitHub: https://github.com/ubaid-dev-01/hsms-backend

## CLI
```bash
cd hsms-backend
vercel --prod --yes
```

## Pipeline
1. Native Git: `vercel git connect https://github.com/ubaid-dev-01/hsms-backend.git`
2. GitHub Actions: set secrets `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`
